# VST 3 Host in Rust

## Introduction

This app loads all VST 3 plugins in /home/user/.vst3 folder and prints its `PFactoryInfo` and `PClassInfo`s.

> Main purpose is to learn the Rust programming language and how to handle VST 3 (using vst3_c_api) plug-ins from with a Rust app

## Get Started

```cmd
git clone https://github.com/rehans/vst3_host_rs.git
cd vst3_host_rs
cargo run
```
